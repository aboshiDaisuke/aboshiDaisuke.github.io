Web App 動画制作

SRT to FCPXML Editor

SRT字幕ファイルをFinal Cut Pro用FCPXMLに変換するブラウザエディタ。 音声波形表示・動画プレビュー・タイムライン上でのIN/OUT点ドラッグ編集など、 本格的な字幕編集ワークフローをすべてブラウザ上で実現。

  • 🎬 動画＆SRTをドラッグ＆ドロップで同時読み込み
  • 🔊 Web Audio APIによる音声波形表示・波形ズーム
  • ✏️ タイムライン上でIN/OUT点を直接ドラッグ編集
  • ⚡ 複数行字幕・文字数オーバー警告・検索＆一括置換
  • 🛡️ IN/OUT点の逆転・重複を防ぐ自動ガード機能

Web App 音声・動画

Media to MP3 Merger

動画・音声ファイルをMP3に変換し、複数ファイルを一本に結合できるブラウザツール。 インストール不要でドラッグ＆ドロップするだけで使えるシンプルさが特徴。

  • 🎵 動画・音声ファイルをMP3に変換
  • 🔗 複数ファイルを順番通りに一本に結合
  • 🌐 インストール不要・ブラウザだけで完結
  • 🖱️ ドラッグ＆ドロップで簡単に操作
