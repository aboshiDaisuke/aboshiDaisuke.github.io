公開中のツール

インストールなしで使える、作業や遊びに寄り添う小さなプロダクト。

01
Web App Video

SRT to FCPXML Editor

SRT字幕ファイルをFinal Cut Pro用FCPXMLへ変換するブラウザエディタ。 波形表示、動画プレビュー、タイムライン編集まで一画面で扱えます。

  • 動画とSRTを同時読み込み
  • 音声波形とズーム表示
  • IN/OUT点のドラッグ編集
  • 検索、一括置換、字幕警告
Live
02
Web App Audio

Media to MP3 Merger

動画・音声ファイルをMP3に変換し、複数ファイルを一本に結合できるブラウザツール。 ドラッグ＆ドロップだけで素早く処理できます。

  • 動画・音声ファイルをMP3変換
  • 複数ファイルの順番結合
  • ブラウザだけで処理完結
  • 軽い操作感のシンプルUI
Live
03
Web App Lottery

おみやげ配布あみだくじ

おみやげや景品をみんなで楽しく分けられる、ブラウザ上のあみだくじツール。 参加人数と商品を入力して、ひとりずつ結果を確認できます。

  • 参加人数をかんたん調整
  • 商品名と数量をリスト登録
  • 抽選スピードを切り替え
  • 結果をひとりずつ表示
